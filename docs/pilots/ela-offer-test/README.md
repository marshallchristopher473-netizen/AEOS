## Rules for every file

1. **This repository is public.** It holds blank templates only. Prospect names, emails, payment records and
   filled logs live in the founder's private store, never in GitHub.
2. **No student data.** No student names, work, scores or records enter any part of this offer or its logs.
3. **Blanks stay blank until the Decision Owner fills them.** Nothing in this pack sets a price, a contact or terms.
4. **Evidence before claims.** Expressed interest is not demand. A test-mode payment is not revenue. A sale is not
   an outcome.
5. **The AEOS platform is not used.** The P0 security gate still governs all real-student-data work and is not
   affected by this pack.
