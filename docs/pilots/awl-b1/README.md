## What this pack is

This pack is everything needed to run the **smallest valid pilot** of the AEOS AI Workflow Lab. It adds
measurement, safeguards and operations to the existing product. It does **not** redesign the product.

The product is a 90-minute live online workshop. Special education professionals build one AI-assisted workflow
that an authorized human can check before it affects instruction, documentation or communication. The beta
has 10–15 paid seats at $79. All practice uses fictional information.

The pilot answers one question: **can this workshop, run safely, produce a measurable skill that people will pay for,
at a cost that could work as a business?** It does not answer whether students benefit, and nothing in this pack
may be used to claim that.

## Selection provenance (read first)

The "previous analysis" that selected this pilot for immediate execution was **not found** in this repository,
its GitHub issues and pull requests, Notion, or Google Drive. The pilot was identified from the most recent AEOS
launch kit in Drive (created 2026-09-23), which matches the pilot requirements (fictional data, paid beta,
approve/revise/reject/escalate review, confidence survey, testimonial form).

**This is an assumption the Decision Owner must confirm** (SOP Stage 0, first item). If a different pilot was
selected, re-target this pack before using it. Do not run it as written.

## Rules that apply to every file

1. **This repository is public.** It holds templates and rules only. Rosters, scores, responses, logs with
   participant data, answer keys and rater anchors **never** go into GitHub. They live in the private evidence
   store (see [03_DATA_MINIMIZATION_PLAN.md](03_DATA_MINIMIZATION_PLAN.md)).
2. **Freeze before selling.** Thresholds, answer keys and analysis rules are frozen and hashed before the first
   seat is sold. A later change is a logged protocol deviation, not an edit.
3. **Evidence before claims.** Testimonials, confidence gains, relevance ratings and attendance are never
   decision evidence. Usage is not learning, and educator acceptance is not student learning.
4. **Fictional data only.** No real student, family or employee information enters any part of this pilot.
5. **The AEOS software platform is not used.** No student data enters AEOS. The P0 security gate still governs
   all real-student-data work and is unaffected by this pilot.

## How to use it

1. DO reads the charter (01) and confirms the pilot selection.
2. The Operator (OP) works through SOP Stage 0 (02). No seat is sold until every Stage 0 item is checked.
3. The team runs Stages 1–7 of the SOP. Logs 06 and 07 and the time log are updated as the SOP directs.
4. OP drafts the completion report (09) at S+10 and finalizes it at S+35. DO makes one decision.
5. Before launch, fix every item that [10_INDEPENDENT_PRELAUNCH_ATTACK.md](10_INDEPENDENT_PRELAUNCH_ATTACK.md)
   lists as a minimum correction, then retest as that file specifies.
