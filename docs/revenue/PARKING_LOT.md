# Parking Lot

Good ideas that are deliberately **not** being built yet. This file exists so that
"not now" does not have to mean "forgotten," and so a new idea has somewhere to go that
is not the current week's work.

## The rule

Nothing moves out of this file until **one deck sprint project has been paid, delivered,
accepted, and measured.** That is the gate. Not "almost sold." Paid and measured.

When a new idea arrives mid-week, add it here in one line and keep going. Deciding
whether it is good is itself a task, and it is not this week's task.

## Parked

| Idea | Why it is parked | What would unparks it |
| --- | --- | --- |
| Additional service packages (tiers, retainers) | Splits attention before one offer is proven | First project paid and measured above target rate |
| A second concurrent client | Doubles admin and revision load at the worst moment | First project delivered and accepted |
| Resource storefront (TPT or similar) | Marketing-heavy, slow to first dollar, no evidence of demand | A paying client asks to buy something off the shelf |
| New AEOS courses or certifications | Large build, long validation cycle, no buyer identified | A buyer with a budget asks for training specifically |
| Daily content production / audience building | Months before it generates a transaction | A validated offer worth pointing an audience at |
| Additional software modules | Build cost before revenue; the platform already has an MVP in progress | Platform MVP reaches pilot, separately from this experiment |
| District licensing | Long procurement, evidence requirements this module cannot yet meet | Validated pilot outcomes from the platform, not from deck work |
| Archival organization service (metadata, inventories, finding aids) | Genuinely strong fit from documented experience — but it is a second offer | First deck project paid; then evaluate as offer #2 |
| Research-to-training conversion (report → facilitator guide) | Same reason; natural second offer, shares the production process | First deck project paid; then evaluate as offer #2 |
| Cold outreach at volume | Five warm contacts first; volume outreach is an hour sink with low reply rates | Five contacts exhausted without a sale |
| Branded website or landing page | The one-pager and a sample do this job for now | A prospect asks for a link you do not have |
| Hiring or subcontracting delivery | No proven margin to pay anyone from | Repeatable projects above target rate |

## Two that are closer than the rest

**Archival organization** and **research-to-training conversion** are the strongest
candidates for offer #2. Both draw on documented employment experience, both reuse the
intake → scope → quality gate → measured delivery machinery already built here, and
neither requires new software. Revisit both — and only both — after the first deck
project is measured.
