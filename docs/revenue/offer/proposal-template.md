# Proposal Template — AEOS Education Deck Sprint

Use this to convert a verbal yes into a written agreement. Replace every `[BRACKET]`.
Keep it to one page; a longer proposal invites negotiation, not agreement.

Send it the same day as the conversation. Momentum is the whole asset at this stage.
