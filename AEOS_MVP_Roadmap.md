# AEOS MVP Roadmap

## Objective
Launch a practical MVP for pilot schools and districts that demonstrates AEOS value quickly while remaining technically feasible.

## Phase 1 — Foundation (Weeks 1-2)
- Finalize product requirements and pilot personas
- Set up repository, backend, frontend, and database scaffolding
- Establish authentication and role-based access
- Create initial data model for schools, students, assessments, and interventions

## Phase 2 — Core MVP (Weeks 3-6)
- Build teacher dashboard
- Implement student profile and assessment intake
- Add AI-assisted feedback generation
- Create intervention recommendation workflow
- Add reporting views for pilot stakeholders

## Phase 3 — Pilot Readiness (Weeks 7-8)
- Prepare onboarding materials for schools
- Configure privacy, security, and audit logging
- Run internal testing with sample data
- Create feedback loop for pilot educators

## Phase 4 — Pilot Launch (Weeks 9-12)
- Deploy to staging and production environments
- Launch with 1-3 pilot schools
- Collect adoption and learning outcome feedback
- Measure time saved and educator satisfaction

## Success Metrics
- 80% of pilot teachers complete at least one assessment workflow
- AI-generated feedback is used in at least 70% of submitted assessments
- Average teacher time-to-complete reduced by 30%
- Pilot partners confirm willingness to expand

## Investor Narrative
AEOS is positioned as a pragmatic AI operations layer for education institutions, combining workflow automation, actionable insights, and measurable productivity gains.
