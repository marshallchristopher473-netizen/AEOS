# AEOS Backend

This directory contains the FastAPI backend used by the teacher assessment review slice.

## Structure
- app/main.py: application entrypoint
- app/api/health.py: health endpoint
- app/api/assessments.py: assessment create/list/read routes
- app/api/assessment_results.py: teacher review create/list/read routes
- app/services/tenant_scope.py: shared tenant-scoped reads and inserts
- app/core/config.py: environment configuration
- app/models/schemas.py: shared request/response schemas

## Run locally

```bash
cd backend
pip install -r requirements-dev.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## Endpoints
- `GET /health`: reports a database connectivity result; `status: ok` alone does not establish readiness.
- `POST /assessments`, `GET /assessments`, `GET /assessments/{id}`
- `POST /assessment-results`, `GET /assessment-results`, `GET /assessment-results/{id}`
- `GET /assessment-results?assessment_id={id}`: reviews for an accessible assessment in the actor's organization.

Assessment and result IDs are generated by the shared insert service. Tenant,
author, and result student identity remain server-derived. Teacher/admin writes
use the existing authorization dependency. Result scores must fit the existing
`NUMERIC(6,2)` columns and must not exceed a supplied maximum.

There is no `/assessments/analyze` or AI generation endpoint in this slice.
See [the workflow guide](../docs/TEACHER_ASSESSMENT_REVIEW.md) for setup and evidence limits.
